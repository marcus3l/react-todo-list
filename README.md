# Checklist de Estudos — lista de tarefas em React

Aplicação para organizar tarefas e estudos em listas de itens pendentes e concluídos, com persistência local no navegador.

## Funcionalidades

- Adicionar, editar, excluir e concluir tarefas
- Separar itens em “Para estudar” e “Concluído”
- Salvar as tarefas no `localStorage`
- Modal de formulário e estado vazio
- Componentes reutilizáveis e estilos organizados por componente

## Tecnologias

React, JavaScript, Vite e CSS.

## Como executar

Requer Node.js instalado.

```bash
npm install
npm run dev
```

O Vite informa no terminal o endereço local da aplicação. Para criar a build de produção, execute `npm run build`.

## Contexto

Projeto prático de estudos em React, desenvolvido como parte de uma formação front-end.
